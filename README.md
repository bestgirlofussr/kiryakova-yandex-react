Проект Stellar Burger с модальными окнами, drag&drop и API.

## 🚀 Демо

**[Смотреть проект в работе на GitHub Pages](https://bestgirlofussr.github.io/kiryakova-yandex-react/)**  
**[Смотреть проект на продакшен-сервере(полноценный деплой с Nginx на сервере Яндекс.Облако)](https://bestburgerinspace.nomorepartiessite.ru/)**

## 🚀 Быстрый старт

git clone https://github.com/bestgirlofussr/kiryakova-yandex-react
cd kiryakova-yandex-react
cp .env.example .env
npm install
npm run dev

## 🔧 .env

# API адрес бургер-эндпоинта (обязательно)

VITE_API_URL=https://norma.education-services.ru/api/

# Название приложения (опционально)

VITE_APP_TITLE=React Burger TS

# Режим отладки (опционально)

VITE_DEBUG=true

## Запуск проекта

# Разработка (localhost:5173)

npm run dev

# Сборка production

npm run build

# Превью сборки

npm run preview
